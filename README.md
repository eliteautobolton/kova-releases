# KOVA Releases

Public APK distribution for KOVA.

The Android source code remains private in `eliteautobolton/kova-android`. Successful `main` builds publish the current installable APK here as a rolling GitHub Release asset named `KOVA.apk`.

Permanent latest-download URL:

`https://github.com/eliteautobolton/kova-releases/releases/latest/download/KOVA.apk`
